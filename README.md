# Emqmalte Tap

## How do I install these formulae?

`brew install emqmalte/tap/<formula>`

Or `brew tap emqmalte/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "emqmalte/tap"
brew "<formula>"
```
